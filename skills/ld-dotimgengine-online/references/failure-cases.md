# 失败案例与针对性回归

以下记录去除了角色资产和会话原文，只保留可复用的因果与修正。具体偏好仅在对应案例启用。

| 观察到的问题 | 修正动作 | 下一轮必查 |
|---|---|---|
| 圆眼、脸型、睫毛、虹膜、瞳孔、高光、眉毛被反复改回 | 把每项具体形状写入区域约束；保留认可脸，优先局部编辑 | 原生尺寸逐项对照，不能只问整体是否像 |
| 整图重生成用通用脸替换已认可脸 | 恢复正确主参考，缩小编辑范围；硬约束采用原像素合成 | 主参考 ID、实际附图、脸部保护与接缝 |
| 将不同版本的脸、身体和服装随意混合 | 区域证据排序、显式替代记录，旧否决图退出默认输入 | 每次输入清单与 current_primary 一致 |
| 新上传原型仍被旧版本压过 | 按用户指示更新基准，重查冻结项与次参考用途 | 新基准确实随生成发送 |
| “不改图、变立体”被理解成只能裁切，正面没有体积 | 冻结设计，允许正面光影、AO 和投影充分变化 | 真实体积感是否满足，是否同时漂移脸与胸饰 |
| 把平面 2D 阴影称为充分 3D 效果 | 诚实说明效果不足，调整体积光影或另议网格方案 | 用户视觉目标，不只看脚本通过 |
| 苗条比例变厚，白色膝部紧身衣断开 | 作为该角色回归项，检查全身与膝部放大图 | 膝部覆盖、两腿比例、材质/衣片连续性 |
| 三个悬浮组件在某视图缺件，左右反了 | 逐件角色坐标与锚点表，每张均纳入；检查分解区 | 角色左右、透视遮挡、线缆端点、组件数量 |
| 参考分解区被当成装饰忽略 | 把每个配件登记为结构证据并标用途 | 是否生成了全部要求的组件 |
| 通过新增装甲、徽记来“丰富细节” | 删除未授权设计；提示中列明禁止新增 | 胸饰、衣片、标识轮廓 |
| 大面积蒙版叠阴影产生多边形、漏色或条带 | 撤销该层；沿真实轮廓裁遮罩、向内羽化、局部放大 QA | 发丝、四肢间隙、服装边缘与背景 |
| 提示词写“锁像素”却没有像素约束 | 改用原像素合成和同尺寸蒙版差异验证 | 蒙版非空、坐标对齐、RGBA 零差异 |
| 放大到 4096 被称原生 4K；二维多视图被称同模型渲染 | 记录原生尺寸、衍生方式及是否实际有网格 | 交付声明与证据一致 |
| 满意正面被后续光影版覆盖 | 原图不可变，候选用新文件名及哈希 | 原始文件哈希与认可记录仍可回溯 |

最终成功案例以认可完整正面为主参考，侧背结构图为次证据，背面先建立材质，再做两侧与独立正面光影版。它减少了设计漂移，但实际仍有眼内与胸饰细节改变；用户接受的是这次视觉结果，不是“零漂移保证”。后续每一版仍须独立验收。
