# 扁平图透明分层与重组

用于将单张扁平图拆成可独立移动的透明层。先查看源图，再确定分层清单；层数、尺寸、坐标和蒙版阈值随当前任务制定，不能从一个成功案例固化。

## 清单、画布与保真边界

- 列出每层的对象归属、前后遮挡、编号、可见区域、需要补画的隐藏区域和用途。按视觉上完整的云团分组，避免机械左右裁半；天空未被请求时，不将天空烘焙进云层。
- 固定共同画布 `W×H`、原点和坐标方向；所有层保留同尺寸完整画布及原位透明留白，不单独裁切对象。说明编号究竟按前后还是交付顺序，重组时显式使用从后到前的层序。
- 优先从源图保留可见原像素。遮挡后方不存在可直接取回的像素，需要补画或生成，并记录范围。半透明边缘还混合了原背景，去污染或重新估计 alpha 可能改变边缘；这些结果不能称无损抠图或恢复原生图层。
- 在使用程序校准位置尺寸、绘制蒙版、处理透明边缘或复合预览前，遵守当前工具规则和本轮用户授权。过去一次允许不自动授权下一任务，也不能用本技能绕过当前图像编辑工具的要求。缺少允许的方式时报告对应限制，继续可独立完成的清单与检查。

## 生成、对齐与边缘

1. 每次生成附上实际参考，描述目标对象、隐藏部分的合理延续及共同画布内的位置尺度；明确真实透明输出。工具提供 `transparent_background` 时必须设 `true`，不能用画出的棋盘、纯色底或扩展名冒充透明。
2. 生成结果常把单个对象放大居中。对照源图选多个分布稳定的地标，如结构交点、端点和转折；先判断平移、统一缩放或局部形变，再选择最小必要变换。记录地标对齐及重采样情况，不能只把对象 bbox 拉伸到目标 bbox 就认定对齐。非均匀缩放可能损坏结构，须另外检查。
3. 蒙版沿实际轮廓绘制，帆间、栏杆间、镂空处也要透明。精细边缘可在约 4 倍尺寸绘制蒙版，再用 Lanczos 回到原画布；倍率是可调方法，坐标、alpha 阈值与羽化宽度由本图验证，不存成通用固定值。
4. 细杆、轨道、线缆可能形成很小的连通域，禁止全局小连通域过滤。也不要全局用最近不透明像素替换半透明 RGB，这会把邻近物体颜色灌入细轨道；只在有污染证据的局部、按结构建立受限修正。
5. 对黑底、白底、棋盘及目标背景查看边缘，检查蓝边、黑线和透明孔隙。海面等长边出现黑缝时，局部补足连续颜色，并建立窄 alpha 过渡；不要整体模糊图层来掩盖接缝。云层允许软 alpha，其最高值不必达到 255。

## 文件、重组与视觉验收

- 每个计数内的透明层都是可完整解码的 RGBA PNG，尺寸恰为共同画布，alpha 同时包含 0 和非零值；全透明、全不透明及只有棋盘图案的输出不通过。最大 alpha 小于 255 的云仍可合格。
- 按遮挡深度从后到前 alpha-over 叠回，对照源图查看位置漂移、比例、重复对象、遗漏部分和云团切割接缝。逐层移动或隐藏，确认移出的物体没有同时残留在主体层；静止预览可能掩盖这类重复。
- 核对细杆连续性、栏杆和帆间孔隙，以及黑白/棋盘/目标背景下的色边。尺寸与 alpha 数值合格不证明这些视觉项通过；重建区域和无法避免的差异须另列。
- 交付编号 PNG、仅含最终文件的 ZIP 和说明。说明共同尺寸/原点、层名和叠放顺序、源像素与重建范围、校准/重采样及剩余差异。重新读取 ZIP 核对文件名、数量及文件哈希。预览图单独标识，不计入透明层数。

## 通用 RGBA 检查与复合辅助

需已存在的 Python 3.10+ 和 Pillow。仅在当前规则及授权允许时运行；不安装依赖，不自动生成、配准、裁切、清边或修改输入。以下占位名称按从后到前排列，尺寸换成当前共同画布：

```sh
# 只读：解码、模式、共同尺寸、每层 alpha 的零值/非零值、软 alpha 和文件 SHA-256
python -B scripts/rgba_layers.py --expect-size 640 360 private/01-back.png private/02-front.png

# 可选：同一顺序生成新 RGBA 复合预览；拒绝覆盖已存在输出
python -B scripts/rgba_layers.py --expect-size 640 360 --output private/recomposed.png private/01-back.png private/02-front.png
```

脚本只接收 8 位 RGBA 静态 PNG，拒绝颜色上下文不一致、空层、实底层及尺寸不符。输出 JSON；成功退出 0，校验/写入错误退出 2，缺 Pillow 退出 3。复合沿用相同的色彩元数据，不转换 ICC，也不是线性光复合；不同宿主的色彩管理可能产生差异。它只能检查文件不变量和按给定层序复合，不能识别假棋盘图案、自动判断遮挡顺序或代替视觉验收。原有 `png_tools.py composite` 是二值保护区像素选择，不是本流程的 alpha-over 叠层。
