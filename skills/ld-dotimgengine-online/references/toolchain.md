# 公开能力适配与实现步骤

这里描述通用编排层，不要求某个专有工具名或隐藏参数。开始时确认现有服务支持哪些能力：参考图输入、图像编辑、局部蒙版、异步状态查询、下载原始结果；缺少某项就记录限制，不能伪装已调用。不要自行安装软件、创建凭据或切换到未授权账户。

## 获取与实际查看

1. 从当前已授权的文件、附件或公开资源获取图像，保存到项目私有工作区。记录参考 ID、原始文件哈希、格式、解码尺寸和用途。先检查文件实际存在、能完整解码；扩展名不能证明格式。
2. 使用宿主的图像查看能力显示完整图，再查看原生尺寸局部。重点看脸、眼部、胸饰、膝部、线缆和配件分解区。只有文本提取、文件列表或尺寸信息，不算看过像素。
3. 如服务不支持原图格式，另存转换副本并记录转换，保留原始文件；不得默默改变透明背景、色彩空间或覆盖参考。

## 每次调用明确绑定参考

维护一个与供应商无关的任务记录：

```text
request = {
  primary_reference: 当前主参考的可读取图像内容或已解析附件句柄,
  secondary_references: 按区域用途选择的结构/材质图像,
  edit_mask: 仅在服务确实支持且当前任务需要时提供,
  instruction: 本轮允许变化 + 冻结项 + 视角/光影 + 组件清单,
  output_request: 当前服务支持的实际尺寸与格式
}
result = image_service.submit(request)
```

这只是语义伪代码，不能照搬为某个 API 的参数。适配器按当前公开文档将文件上传、可访问 URL 或附件句柄转换为该服务真实输入；检查参考确实随本次请求发送，不依赖“上次应该记住了”。无法附齐必需参考时停止该次生成并说明缺项。蒙版黑白语义因服务而异，须确认后转换；本技能脚本的白色表示**保护原像素**，不代表编辑服务同样定义。

## 异步生成与原始输出

```text
submit -> running -> 查询状态/等待回调 -> succeeded | failed | cancelled | unknown
```

保存任务标识仅用于项目私有追踪，不能写入公开案例。异步未完成不能交付为成功；等待时按服务公开限额采用退避轮询并给用户简短进度。超时标为 unknown，先查询既有任务或结果，避免重复提交和重复费用；明确失败后才评估是否在原授权内重试。需要新登录、付款或权限时停止依赖步骤。

成功后下载服务原始输出，先保存不可覆盖的新文件并计算哈希。查看实际内容、原生尺寸、格式、透明度和安全可读性；返回了 URL 或成功状态不等于本地文件有效。衍生处理另存，登记父文件哈希和处理方式。若结果错误，保留为候选/否决记录，不能覆盖当前认可图。

## 裁切、重采样、重生成与合成

| 操作 | 实际改变 | 能否创造新的视角/真实细节 |
|---|---|---|
| 裁切 | 画布范围与坐标 | 不能；跨视图比较前须明确坐标映射 |
| 普通重采样 | 像素网格与插值 | 不能声称原生新细节；长边 4096 是输出尺寸 |
| 生成式放大/重生成 | 重新推断像素，可能改设计 | 可能补细节，也可能改眼睛/配件，必须重新验收 |
| 原像素区域合成 | 对齐后按蒙版选择/混合像素 | 可确定性保留指定区域，不保证其他区域设计正确 |
| 真实 3D 渲染 | 由网格、材质、灯光与摄像机生成 | 需真实资产和渲染证据，二维图组不能替代 |

硬冻结场景：候选与原图使用同尺寸、同坐标和相容色彩解释；二值保护蒙版白色区域从原图复制 RGBA，黑色区域取候选。使用[验收命令](acceptance.md)输出新 PNG，再在**原生尺寸**验证保护像素。脚本不自动配准，不做色彩管理、不处理 16 位色深；需要这些能力时换合适工具并说明验证边界。

柔和阴影不能用大块多边形直接盖人物：沿实际轮廓建立遮罩，避开背景与保护区域；向轮廓内部羽化，局部放大检查边缘、缝隙和接触区。半透明混合会改变边缘像素；硬保护区及其过渡边界必须设计清楚并单独验证。背景漏色、条带、平面切块明显时撤销该合成，不能继续叠层掩盖。

## 最终文件与附件

逐张目视验收后验证 PNG 完整解码、真实尺寸、文件哈希和需要的保护蒙版差异；记录原生生成尺寸与交付尺寸。用当前宿主可用的附件/文件链接交付每个 PNG，打开或回读交付文件确认路径指向最终版本。链接可访问性无法验证时如实说明，不以仅显示内部路径代替附件成功。公开仓库只收方法和合成测试，不收角色图或私有任务记录。
