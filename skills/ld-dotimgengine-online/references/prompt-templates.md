# 通用提示词模板

先填写参考清单再取用模板。大括号是需按任务替换的字段；模板不定义真实 API 参数。每次调用必须实际附图，不能只复制下面的文件名。

## 新立绘候选

```text
任务：创建{角色概念}的完整立绘候选。
明确设计要求：{身份/轮廓/比例/五官/服装/配色/配件}。
参考用途：{参考 ID 与各自授权用途}；尚未确认的设计：{待确认项}。
画面：{全身/姿态/背景/画幅}。不要裁掉头顶、脚底或悬浮组件。
本轮仅提出{候选目标}，不要把新设计写成已经获得用户认可。
```

## 局部细节修正

```text
主参考：{current_primary}；只以它决定当前角色身份。
本轮唯一改动：{区域与具体差异}。
冻结：{已认可脸/轮廓/比例/服装/主配色/其他组件}。
区域证据优先级：{区域 -> 参考 ID 列表}。
眼部若不是本轮目标，不改变眼型、脸型、睫毛、虹膜、瞳孔、高光和眉毛。
禁止：通用风格脸替换、附带重新设计、新装甲/符号、组件移侧或丢失。
输出为新候选，保留原文件。硬像素冻结区域由后续原像素合成并验证，不能靠提示词宣称锁定。
```

眼部是目标时，分别描述圆度/眼裂、睫毛走向、虹膜边界、瞳孔形状/位置、高光数量/位置、眉毛形状和脸颊/下颌；不要用“更好看”替代用户具体修正。已认可眼睛内部的层次不得因追求 3D 风格而随意改成另一种眼睛。

## 保持设计、加强立体光影

```text
主视觉参考：{最后认可的完整图}；设计以该图为准。
任务：保持{当前视角}，制作有充分体积感的 toon 3D 风格二维效果图。
不重新设计人物身份、轮廓、苗条/厚重比例、五官结构、服装、胸饰和主配色。
允许改变：{主光方向/柔和投影/接触阴影/AO/高光/材质明暗}。
正面也需要清晰而柔和的体积光影；不要只裁切、放大或加一层平面阴影。
保留：{当前角色专属要求，例如白色紧身衣完整覆盖膝部、线缆端点}。
三个组件：{逐件 ID、角色自身左右/前后/锚点及可见性要求}。
禁止增加新装甲、标识或替换已认可脸。另存新 PNG，原始正面不覆盖。
```

## 多视图：逐张调用

```text
本轮仅生成{背面/角色自身左侧/角色自身右侧/正面光影版}。
主参考：{认可完整正面 ID}，决定身份、脸和设计。
次参考：{结构图 ID -> 只补充侧背服装结构}；{认可背面 ID -> 只对齐材质与 AO}。
仅改变指定视角与光影，不改变设计。保持全身正交风格、统一人物高度与姿态。
沿用{材质/光照风格}，保持{膝部覆盖/线缆/配件/服装结构}。
三个组件全部纳入此视图：{组件 ID 与角色自身坐标}。
遮挡按当前视角合理解释，不能简单镜像、穿透显示或换到屏幕同一侧。
不新增装甲或符号；输出独立 PNG 候选，逐张核查，原始正面始终保留。
```

首次背面建立材质；后续侧面和正面仍必须附主正面，不能只用上一张输出逐代漂移。若工具可传参考数量不足，只选择足以覆盖本轮必要证据的集合；必需参考放不下时报告能力限制，不默默丢弃主参考。

## 重试修正

```text
上一候选否决原因：{观察到的具体差异}。
当前主参考仍是{ID}；否决图只用于定位问题，不成为新身份参考。
本轮只修正{最小区域/视角/光影问题}，继续冻结{已通过项}。
回归检查：{这次错误 + 之前用户反复强调项}。
```

连续失败时先核对实际输入、版本优先级和服务能力，再决定局部编辑、合成或新一轮生成。不能无分析地重复同一整图提示，也不能以“像素锁定”措辞掩盖能力缺口。
